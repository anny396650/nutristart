# 營養追蹤

記錄每天吃了什麼、喝多少水、體重變化的小工具。手機開網頁就能用，可以加到主畫面像 App 一樣。

**線上版：https://nutristart.pages.dev**
**原始碼：https://github.com/anny396650/nutristart**

---

## 開始使用

### 1. 加到手機主畫面（建議）

**iPhone 必須用 Safari**（Chrome 在 iOS 上沒有這個功能）：

1. Safari 開上面的網址
2. 底部中間「分享」鈕 ↑
3. 往下滑 →「加入主畫面」

之後從主畫面開就是全螢幕，跟 App 一樣，也能離線使用。

Android 用 Chrome 開，選單裡有「安裝應用程式」。

### 2. 設定你的每日目標

**設定 → 每日目標**。預設是台灣的每日參考值（2000 大卡、蛋白質 60g…），
改成適合自己的。不知道抓多少的話，先用預設值記一週，再回頭調。

### 3. 設定你吃的保健品

**設定 → 保健品組合**。預設只有兩組範例（早餐綜合維他命、睡前鈣片），
改成你自己實際吃的：可以改名稱、改時段、增刪品項。

維他命百分比那幾欄照罐身標示填，填了之後「今天」頁的維他命面板才會算。

### 4. 常吃清單

**設定 → 常吃清單**。內建 12 樣常見食物（白飯、雞胸肉、豆漿…），
數值是概略值，可以自己改，也可以整批刪掉重建成你常吃的東西。

在「今天」頁點一下就記錄，用得越多的會自動排到前面。

## 拍照 / 文字估算（選用）

不設定也能用，只是要手動輸入。想用 AI 估算的話要自己申請一把 Gemini 金鑰：

1. 到 [aistudio.google.com/apikey](https://aistudio.google.com/apikey) 用 Google 帳號登入
2. 按「Create API key」，複製那串金鑰
3. App →「設定 → AI 估算」貼上 → 按「測試連線」

**免費的**，有每日額度限制，一般個人使用綽綽有餘。

> 金鑰只存在你自己的手機裡，直接跟 Google 通訊，不會經過任何其他人的伺服器。

**拍照的小技巧**：如果包裝上有營養標示，把標示那面一起拍進去，
AI 會直接讀標示的數字，比用外觀猜準得多。估算結果的「依據」會寫「依包裝標示」。

沒有標示的食物（自助餐、家常菜）就是估算，誤差大約 ±20–30%，當趨勢看就好。

## ⚠️ 記得備份

**資料只存在你這台裝置的瀏覽器裡，沒有雲端。**

這些情況資料會消失：

- 清除瀏覽器的網站資料
- 手機儲存空間不足時被系統清掉
- 換手機

**所以請每個月匯出一次**：設定 → 備份與還原 → **匯出 JSON**。

手機上按下去會跳出分享選單，可以 AirDrop 到電腦、存到「檔案」或雲端硬碟。

要還原時：設定 → 備份與還原 → 匯入 JSON。

> CSV 是給試算表看的，**不能還原**。能還原的只有 JSON。

## 其他

- **點品項名稱**可以直接改數字，不用刪掉重加
- **複製前一天**：菜單固定的話一鍵搞定（是追加，不會蓋掉現有的）
- **保健品少吃一樣**：整組打勾後，在「今天吃了」按那一項的 ✕ 就好，其他項會留著
- **趨勢頁**可以記體重和 InBody 數據，看長期變化
- 日期可以直接點，跳到任何一天補記

## 想自己改？

整包程式碼就是 `index.html` + `styles.css` + `app.js` 三個檔案，
**沒有框架、沒有 build step、沒有後端**，用瀏覽器直接開就會動。

1. 下載：右上角 **Code → Download ZIP**，或
   ```bash
   git clone https://github.com/anny396650/nutristart.git
   ```
2. 本機預覽：`python3 -m http.server 8765`，開 `http://localhost:8765`
3. 改完丟到任何靜態主機就能用（Cloudflare Pages、Netlify、Vercel、GitHub Pages 都行）

**想請 AI 幫你改的話**，把 [AI_GUIDE.md](AI_GUIDE.md) 連同專案一起丟給它。
那份寫了資料結構、關鍵設計、以及這個專案踩過的坑，AI 讀完比較不會改壞。

### 部署到 Cloudflare Pages（免費）

```bash
npx wrangler pages deploy . --project-name=你想要的名字
```

第一次會開瀏覽器要你登入。之後每次改完重跑這行就更新了。

## 你的資料去哪了？

**沒有後端、沒有帳號、沒有資料庫、沒有分析工具、沒有第三方 CDN。**

這個 App 對外只會連**一個**地方：

| 對象 | 什麼時候 | 送出什麼 |
|---|---|---|
| Google Gemini | 你按「拍照記錄」或「文字描述」時 | 那張照片或那句描述，用**你自己的**金鑰 |

**就這樣，沒有別的了。** 字型是自架的，所以連 Google Fonts 都不會連——
不像多數網頁那樣每次開啟就把你的 IP 送給第三方。

你的飲食紀錄、體重、體組成資料**從來沒有離開過你的裝置**，
它們存在瀏覽器的 localStorage，開發者看不到、任何伺服器上都沒有副本。

**不填 Gemini 金鑰的話，這個 App 完全不對外傳送任何東西。**

### 關於你的 Gemini 金鑰

- 存在你自己裝置的 localStorage，只在呼叫 Gemini 時放進請求標頭
- **只在你信任的網址填金鑰。** 這是開源專案，任何人都能改一份部署到別的網址，
  惡意版本可以偷金鑰——這對所有開源前端工具都一樣
- 覺得不對勁隨時到 [Google AI Studio](https://aistudio.google.com/apikey) 刪掉重發一把

### 安全設計

- 已設 `Content-Security-Policy`，限制頁面只能連到必要來源
- 所有使用者輸入渲染前都經過跳脫處理，沒有 `eval` / `new Function` / `document.write`
- 沒有後端就沒有可以被入侵的資料庫

- 字型自架（`fonts/` 資料夾），中文用系統內建字型，不依賴任何 CDN
